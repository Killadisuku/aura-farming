# AURA

**Give good energy. Get recognized.**

Social reputation app. Give Aura Points for kindness, courage, humor, charisma, and cool moments.

Aura has no cash value and cannot be purchased.

## Live

**https://aura-farming-yasar9.vercel.app**

Production on Vercel. No login wall. Open the link, use the demo profile, give Honor or Dishonor.

Privacy: https://aura-farming-yasar9.vercel.app/privacy.html

## GitHub + Vercel

Repo: https://github.com/Killadisuku/aura-farming

Vercel project `aura-farming` is linked to this repo. A push to `main` deploys production automatically.

## Local

```bash
npm install
npm run dev
```

The app opens as Ahmed (demo) so you can try it immediately.
