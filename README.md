# AURA

**Give good energy. Get recognized.**

Social reputation app. Give Aura Points for kindness, courage, humor, charisma, and cool moments.

Aura has no cash value and cannot be purchased.

## GitHub + Vercel

Repo: https://github.com/Killadisuku/aura-farming

Vercel project `aura-farming` is already linked to that repo. A push to `main` deploys automatically.

```bash
git init
git add .
git commit -m "Launch AURA"
git branch -M main
git remote add origin https://github.com/Killadisuku/aura-farming.git
git push -u origin main
```

## Local

```bash
npm install
npm run dev
```

Tap **Enter as Ahmed (demo)** to skip onboarding.
